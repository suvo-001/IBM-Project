# Employee Visitor Management System

A simple full-stack web application for managing employee visitors digitally. It allows users to add visitor details, track check-ins, and manage visitor check-outs through a clean dashboard.

## Features

* Add visitor details
* Track currently checked-in visitors
* Record visitor check-out
* View total visitors
* View visitor status
* Store visitor records in MongoDB
* Simple and responsive dashboard

## Tech Stack

* **Frontend:** React, Vite
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **API:** REST API
* **Version Control:** Git & GitHub

## Visitor Details

The system stores:

* Visitor Name
* Phone Number
* Email
* Purpose of Visit
* Person to Meet
* Department
* Check-in Time
* Check-out Time
* Visitor Status
